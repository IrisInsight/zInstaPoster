# zInstaPoster — brand

Deliberately scrappy. The logo is the only loud thing in the app; keep the UI chrome clean.

| File | Use |
|---|---|
| `mark.svg` | App icon, favicon, avatar. Square, safe down to 32px |
| `logo.svg` | Horizontal lockup. Header, login screen, docs |
| `mark.png` / `logo.png` | 2x raster previews. Prefer the SVGs in the app |

## Colors

| Token | Hex | Use |
|---|---|---|
| `ink` | `#1C1A17` | Outlines, wordmark |
| `flame` | `#E8563A` | Accent — the `z`, speed lines, underline |
| `paper` | `#FFF6E9` | Logo background field |
| `blush` | `#FFD7C2` | Photo window fill |
| `dust` | `#C9C2B6` | The polaroid chin scribble |

## Wordmark

`'Arial Black', 'Helvetica Neue', Impact, sans-serif` at weight 900. The `z` is lowercase,
oversized, tilted -8°, and always in `flame`. If you need the logo where fonts can't be
relied on, convert the text to paths — do not substitute a lighter weight.

## Don't

- Don't straighten the polaroid or regularize the wobble. The lopsidedness is the point.
- Don't recolor the accent per tenant. This is the tool's identity, not a client's.
- Don't put the logo on tenant-facing output. Rendered slides carry the *tenant's* brand
  and nothing else — a practice's Instagram post must never carry the tool's mark.
